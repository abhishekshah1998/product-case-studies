# Product Case Studies

Selected examples of how I frame problems, make product decisions, work across functions, and measure outcomes.

These narratives are intentionally sanitized. They use rounded results already shared publicly and omit employer data, customer information, internal documents, and proprietary implementation details.

## Cases

| Case | Product challenge | Selected outcomes |
| --- | --- | --- |
| [AI-enabled workforce operations](case-studies/ai-enabled-workforce-operations.md) | Turn fragmented, reactive operating workflows into a measurable allocation platform | Labor-model accuracy improved from ~70% to 92%; manual reassignments reduced 15% |
| [Self-serve data onboarding and integrations](case-studies/self-serve-data-onboarding.md) | Reduce services-heavy onboarding while improving data quality and customer control | Setup time reduced 40%; self-serve adoption increased 25%+ |
| [Customer engagement score](case-studies/customer-engagement-score.md) | Create an actionable measure of bank-customer engagement from fragmented behavioral signals | PoC targeted a $27M+ ARR opportunity; team milestone completion accelerated 30% |

## Case-study format

Each case covers the user and operating context, evidence, product decisions, trade-offs, execution, results, and what I would test next. The focus is product judgment rather than confidential implementation detail.
