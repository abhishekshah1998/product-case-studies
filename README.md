# Product Case Studies

**Product judgment under real operating constraints**

This collection shows how I frame ambiguous problems, evaluate evidence, make product decisions, align teams, and measure outcomes. The cases focus on the reasoning behind the work—not just the shipped feature.

## How each case is structured

Each narrative covers:

1. User and operating context
2. Evidence and problem framing
3. Product decisions and trade-offs
4. Cross-functional execution
5. Outcomes and measurement
6. What I would test next

## Evidence and confidentiality

These narratives are intentionally sanitized. They omit employer data, customer information, internal documents, and proprietary implementation details. Every case includes an evidence-status note, and metrics are removed or qualified when their definitions cannot be reconciled confidently.
